# Bus Hive

## 📌 Descrição
Uma aplicação que auxilie no cotidiano de quem use transporte público.

## 🎯 Objetivo
O objetivo é criar uma maneira de administrar e auxiliar pessoas que utilizam transporte público.

## 🧩 Tecnologias Utilizadas
GitHub, VScode, Firebase, NodeJS, etc.

### Backend (2TW)
- Node.js
- Firebase

### Mobile
- React Native

## 🚀 Funcionalidades
- Mapa interativo das rotas de ônibus;
- Recarga de cartão;
- Agenda de horários.

## 📂 Estrutura do Projeto
Terá as pastas de imagens, CSS, Views, Controller, Model, Router, etc.

## ▶️ Como Executar
Instale e utilize o comando "npm run dev" ou "node app.js".
