# BusHive

## 📌 Descrição
Uma aplicação que auxilie no cotidiano de quem usa transporte público (especialmente ônibus).

## 🎯 Objetivo
O objetivo é criar uma maneira de administrar e auxiliar pessoas que utilizam transporte público, através de recarga de cartão, mapa interativo e agenda de horários.

## 🧩 Tecnologias Utilizadas
GitHub, VScode, Firebase, NodeJS, Render, React Native, Expo Snack, etc.

### Backend (2TW)
- Node.js
- Firebase

### Mobile
- React Native

## 🚀 Funcionalidades
- Mapa interativo das rotas de ônibus (apenas ilustrativo);
- Recarga de cartão (apenas ilustrativo);
- Agenda de horários.

## 📂 Estrutura do Projeto
Terá as pastas de imagens, CSS, Views, Controller, Model, Router, Config, etc.

## ▶️ Como Executar
Instale o arquivo no github e use o comando "npm install" para instalar a pasta node_modules. Em seguida, execute o comando "node app.js" ou "npm run dev" para nodemon.

## 🌐 Deploy
https://bus-hive-1.onrender.com

## 📱 Aplicativo Mobile
O aplicativo será feito em React Native no Expo Snack. Para testá-lo, tem a opção de escanear QR Code no aplicativo do Expo Snack ou teste local no navegador.
